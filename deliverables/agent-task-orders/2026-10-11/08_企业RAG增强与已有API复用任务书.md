# T6 企业RAG增强与已有API复用任务书（任务包1.3）

## Goal / Spec / Architecture
目标：在中小企业/工厂常见资料上实现有权限、可追溯、可更新、可测成本的真实知识检索与任务应用；提升企业适配性，不以接入数量或向量数量证明质量。
用户来源：2026-10-11本会话。希望常见企业/工厂资料、多格式、低成本；用户已有一些API，并亲自建立了IMA公共知识库。**所有权是用户陈述；API是否存在、可调用范围及FY是否已接通仍需证据。**
架构原则：审查并复用既有KB/检索/API，不先创建第二套知识基座。外部知识服务作为可替换适配器；受限、失效或到期时明确降级/失败，不暗换来源或伪造答案。
公共待办：todo-1791716228-6810c8。以下是审查/需求规格，实施接口与阈值由Codex在证据返回后冻结。

## 阶段A：事实整理，可立即执行
- [ ] 输出 rag-readiness.md：当前入口→解析→存储→检索→权限→引用→真实调用→测试的完整链，绑定commit和精确来源。代码存在不等于实际验证。
- [ ] 输出 integration-register.csv：integration_id、提供者/用户资源、所有权来源、文档URL/版本、现有代码路径、认证方式（仅类型）、许可/费用/额度来源、检索/引用/写入/导出能力、租户隔离、超时/重试、当前验证状态。
- [ ] 将用户自建IMA公共知识库列为优先核验候选：确认知识库标识与可分享地址（不索取密钥明文）、官方支持的接口/导出路径、引用精度、更新时效及使用授权。公共可读不自动等于有程序化API、私有权限、可无限抓取或可商业再分发。
- [ ] 没有可支持API时标blocked/unsupported；不通过登录绕过、未批准爬取或第三方上传解决。保留本地知识库独立运行路径，防止外部资源成为单点。
- [ ] 建立格式能力矩阵：PDF文本/扫描PDF、DOCX、XLSX/CSV、PPTX、TXT/Markdown、HTML及图片OCR；工厂规程、设备手册、质量/检验表、合同、项目资料和修订版本作为候选。旧Office、CAD图纸、复杂公式、邮件与专有格式单独列边界，不宣传全部已支持。
- [ ] 当前资料规模未知；按实际样本统计文件数/页数/字节/表格/扫描比例/语言/更新频率/角色权限。“普通中小企业”不是可据以声称统计规模的事实。
- [ ] 可用公开/获授权脱敏语料构造1k/10k/100k文件的工程压力分档，记录生成方法及真实内容分布；这些是测试档位而非典型企业规模。小云机不强制达到最高档，未测档位保持not tested。

## 增强规格与验收项（每项单独映射需求ID、代码及测试）
| 领域 | 要求 | 必须验证的反例 |
|---|---|---|
| 解析 | OCR/布局、标题段落、表格单元格、页码/章节、内容哈希与版本；失败进入隔离队列 | 扫描件、跨页表格、乱码、损坏/超大文件不能默默变空索引 |
| 索引 | 幂等批量导入、断点恢复、增量更新、版本化chunk/embedding、删除与撤权传播 | 同名不同版本、重复导入、途中中断、旧缓存残留 |
| 权限 | tenant/project/document级授权在召回及上下文组装前生效，输出/缓存也隔离 | 跨租户相似内容、权限收回后旧缓存、通过引用URL绕过权限 |
| 检索 | 现有混合召回/embedding/rerank可配置，按任务域评价择优而非盲目增组件 | 精确编号/型号、缩写、相反规程版本、多跳及表格数值 |
| 回答 | 来源页/段/表格定位、版本/时效、证据不足拒答、冲突提示 | 无答案问题、诱导编造引用、过期文件、资料中的prompt注入 |
| 业务应用 | 检索结果可进入受控编排/产物流程，保留依据与审批 | 不允许知识文档自身授权执行危险工具或改变政策 |
| 运维 | 队列、限流、隔离、指标、备份恢复、可重建索引、API失败降级 | 模型/外部IMA不可用、配额用尽、并发导入、磁盘耗尽 |

## 测量与成本门
- 冻结业务问题集、标准证据和答案边界，区分调优集/独立留出集。包含规程编号定位、表格数据问答、跨文档依据、版本冲突、无答案、权限拒绝。
- 检索测Recall@k/nDCG或适用排序指标；回答测证据支持、引用正确、拒答与数值正确；业务测完成率、人工修正、重做及可交付产物。模型自评不能单独验收。
- 每组记录真实内容规模、索引量、硬件、provider/版本、参数、并发、冷/热状态、p50/p95、失败率、导入吞吐、单任务及建库/更新费用。
- 先在已确认资源和资料样本上测基线，再决定缓存、增量embedding、批处理、重排候选数及外部API。不承诺2–3G机器承载任意企业数据或本地大模型。
- 发布阈值必须由Codex根据业务重要性与测量冻结；执行Agent不得自行改阈值、换题或只报最佳一次。允许受控负载和拒绝超限，不允许无声丢任务。
- 自迭代仅使用获授权反馈，在权限域内提出候选检索/切块/路由策略，经留出集、成本、安全和回滚门后晋升；禁止跨客户泄露及用评测答案污染记忆。
