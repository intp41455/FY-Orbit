**几何口径（全部文件同源）**

- 图形标渐变：`linear-gradient(150deg, #35E0C8, #1FA894)`。SVG 内用
  `x1=0.1585 y1=-0.0915 x2=0.8415 y2=1.0915`（对正方形 bbox 的 CSS 150° 精确换算），
  与落地页 `.mark` 的 `linear-gradient(150deg,var(--accent),#1FA894)` 一致。
- 字标字母色 `#04211D`（实测于 `#35E0C8` 上 ≈10.2:1，AAA）。
- FY 为**手写多边形路径**（原生网格 146×100），不是文字，因此任何渲染器下形状一致：
  - `F`：`M0 0 H64 V24 H24 V42 H56 V66 H24 V100 H0 Z`
  - `Y`：`M72 0 H94 L109 26 L124 0 H146 L120 44 V100 H98 V44 Z`
- 圆角 = 0.26×边长。规格书在「34px 方标圆角 10px（≈0.294）」与「512px 图标圆角 12%」
  之间存在冲突，此处取折中值 0.26 并在 `render_assets.py` 的 `PRESETS["mark"]` 里集中可调。
- 安全区：图形标四周留白 ≥ 0.25×边长（`logo-mark.svg` 为精确 0.25；横版 0.5；竖版 0.4），
  满足「不小于图形标边长的 1/4」要求。

## 2. 怎么重新生成

```bash
cd assets/brand
bash render_assets.sh
```

或直接：

```bash
python render_assets.py
```

**环境要求**：Python 3.11+ 与 Pillow。**不联网、不安装任何东西。**

脚本每次运行都会打印一张**实测表**（文件名 / 实际像素尺寸 / 字节数 / 色彩模式），
以及三项自动校验结果：

- **缺字检查**：把每个中文字形的墨迹盒与 `.notdef` / `U+FFFD` 比对，相同即报缺字。
- **版式校验**：任何文字块的墨迹包围盒越出安全边距、或任意两块相互重叠，都会打印告警。
  当前状态：**0 条告警**。
- **色板审计**：用凸组合模型判定每个主色能否由品牌色板（含 alpha 叠加与渐变插值）解释。
  当前状态：两张 OG 图**全部落在品牌色板内**。

> SVG 是手写文件，不由脚本生成；脚本只负责位图派生物。改 Logo 请直接改 SVG，
> 并同步 `render_assets.py` 里的 `FY_F` / `FY_Y` 多边形常量（两者必须保持同形）。

## 3. 字体依赖与许可提示（重要）

脚本内置的中文字体查找链，按顺序命中即用：

```
C:\Windows\Fonts\msyhbd.ttc   (Microsoft YaHei Bold)   ← 本次实际命中
C:\Windows\Fonts\msyh.ttc     (Microsoft YaHei)        ← 次级字重实际命中
C:\Windows\Fonts\simhei.ttf   (SimHei)
```

全部找不到时脚本会**直接报错退出**，不会静默输出豆腐块，也**不会联网下载字体**。

⚠️ **许可提示**：微软雅黑是 Windows 随附的商业字体，**不可再分发字体文件**。
当前产出的 PNG 只是用本机字体栅格化出的位图（常规使用场景），但若要让物料体系
完全落在规格书要求的 SIL OFL 开源口径内（跨机器一致 + 可商用无争议），建议：

1. 安装 **思源黑体 / Noto Sans SC**（SIL OFL，免费可商用）；
2. 把 `render_assets.py` 的 `FONT_CHAIN_BOLD` / `FONT_CHAIN_REG` 首项指向该字体文件
   （例如 `C:\Windows\Fonts\SourceHanSansSC-Bold.otf`）；
3. 重跑 `bash render_assets.sh` 即可全量换字。

SVG 文件不含任何字体依赖：FY 字标是几何路径，中文文本层用
`font-family="'PingFang SC','Microsoft YaHei',sans-serif"` 由打开者本机字体渲染，
不含嵌入字体、不含外链。

## 4. 中文产品名待定时，怎么一次性替换全部物料

中文名尚未拍板，因此**本批不产出中文名成品图**，中文一律做「可变文本层」。
替换入口只有两个地方，改完重跑脚本即可：

### 4.1 位图类（favicon / OG 图）

改 `render_assets.py` 顶部的 `TEXTS` 常量：

```python
TEXTS = {
    "positioning":     "本地多智能体搭建与调度平台",   # ← 对外主标
    "positioning_l1":  "本地多智能体",                # ← 竖版第一行
    "positioning_l2":  "搭建与调度平台",              # ← 竖版第二行
    "subtitle":        "可视化搭建 · 代码级自定义 · 无需注册联网",  # 副标（已定稿，一般不改）
    "selling_points": [...],                          # OG 图三行卖点
    "signature":       "FY · Find Yourself",
}
```

然后 `bash render_assets.sh`。标题字号会自动重新收敛，**不需要手工调字号**。

### 4.2 矢量类（SVG）

| 文件 | 要改的元素 |
|---|---|
| `logo-horizontal.svg` | `<text id="brand-positioning">`、`<text id="brand-subtitle">` |
| `logo-horizontal-light.svg` | 同上两个 id |
| `logo-vertical.svg` | `<text id="brand-positioning-l1">`、`id="brand-positioning-l2"`、`id="brand-subtitle"` |

⚠️ 若新名称**明显更长**：

- 横版：把 `viewBox` 的 width（当前 576）按要求放大，例如 13 字→16 字约需 +90；
- 竖版：重新分配两行字数（当前 6 + 7），并确认单行宽度 ≤ 384（480 减左右安全边距）。

当前实测（Microsoft YaHei）：

- 横版：定位语 132+396=528 ≤ 540 ✅；副标 132+306=438 ✅
- 竖版：行1 281 / 行2 328 / 副标 323，均 ≤ 384 ✅
